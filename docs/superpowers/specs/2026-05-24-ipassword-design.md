# "信息保险箱" 产品设计文档

> 版本 1.0 | 2026-05-24 | 状态：待实现

---

## 1. 产品定位

"信息保险箱"是一个**个人信息保险箱**，用于安全储存和管理用户的密码、银行卡、证件及敏感笔记。Android + Windows 双端。

---

## 2. 核心功能

### 2.1 四种储存类型

| 类型 | 字段 | 照片 |
|------|------|------|
| 🔑 登录密码 | 平台名、用户名、密码、邮箱、手机号、网址、备注 | 无 |
| 💳 银行卡 | 银行名称、卡号、持卡人、有效期、CVV、取款密码、备注 | 正面照（最多3张） |
| 🪪 证件 | 证件类型、证件号、姓名、签发机关、有效期、备注 | 正反面（最多3张） |
| 📝 安全笔记 | 标题、自由文本 | 无 |

### 2.2 智能分类

- 内置常见平台分类表，添加时根据"平台名"或"网址"自动推荐分类
- 用户可手动修改分类
- 支持自定义文件夹

### 2.3 安全等级

每条记录可设两个等级：
- **基础**：解锁 App 后自由查看/复制
- **加强**：每次查看密码或复制时需二次验证（指纹或主密码）

### 2.4 快速查找

- 主界面顶部常驻搜索栏，实时筛选
- 独立搜索页，结果按类型分组
- 可搜：平台名、用户名、邮箱、手机号、卡号、证件号、备注

### 2.5 主界面结构

- **信息保险箱**（主标签）：搜索栏 + 类型筛选 + 文件夹筛选 + 条目列表
- **搜索**（标签）：全屏搜索
- **我的**（标签）：设置、安全、文件夹管理、导入导出、关于

### 2.6 照片/附件

- 每条记录最多 3 张照片
- 照片与数据一起加密储存
- 不以明文形式出现在手机相册

---

## 3. 安全设计

### 3.1 解锁方式

- 主密码（必设，首次使用时创建）
- 指纹/人脸识别（快捷解锁，Android 生物识别 / Windows Hello）

### 3.2 加密方案

```
用户主密码
    → PBKDF2 密钥派生（10万+ 次迭代，随机盐）
    → AES-256-GCM 加密
    → 密文存入本地 SQLite 数据库
```

- 加密库：`gt_secure` + `flutter_secure_storage`
- 主密钥仅存内存，不落盘
- 忘记主密码 = 数据永久无法恢复（设计意图）

### 3.3 辅助安全措施

- 复制密码后 60 秒自动清空剪贴板（仅清除 App 自己复制的内容，不动用户自行复制的内容）
- App 切换到后台超过设定时间后自动锁定
- 错误解锁尝试次数限制（连续错误后增加等待时间）

## 4. 界面风格

- 跟随系统自动切换浅色/深色主题
- 参考 1Password、Bitwarden 等成熟产品设计
- 使用 Google Material Design 3 规范

---

## 5. 技术选型

- **框架**：Flutter（一套代码，Android + Windows 双端）
- **加密**：gt_secure + flutter_secure_storage
- **本地数据库**：SQLite（加密储存）
- **状态管理**：待定（根据 Flutter 生态选最合适的）

---

## 6. 开发路线

| 阶段 | 内容 | 目标 |
|------|------|------|
| Phase 1 | Android 本地版 | 手机端完整可用 |
| Phase 2 | Windows 本地版 | 电脑端完整可用 |
| Phase 3 | 双端扫码同步 | 二维码加密传输，局域网互通 |
| Phase 4 | 云端加密储存 | 数据上云，多设备自动同步 |

每阶段完成后即可投入使用，不需要等全部做完。

## 8. 界面流程总览

```
打开 App → 主密码/指纹解锁 → 信息保险箱（主列表）
                                  ├── 搜索栏（顶部常驻）
                                  ├── 类型筛选（全部/密码/银行卡/证件/笔记）
                                  ├── 文件夹筛选
                                  ├── 点击条目 → 详情页（查看/复制/编辑/删除）
                                  │              └── 加强安全条目 → 二次验证
                                  └── + 按钮 → 选类型 → 填表单 → 保存
```
