"我密码" 技术方案对比

同一个软件，三种实现路径。你是个人用户，Android + Windows 双端。

A

跨平台框架（推荐）

用一套代码同时搞定 Android 和 Windows。Flutter 或 React Native，写一次，两平台都能跑。

优点

  • 开发效率高，不需要分两个团队
  • 界面统一，体验一致
  • 维护成本低，改一处两平台生效
  • Flutter 支持桌面端越来越成熟

缺点

  • 性能略逊于原生（密码管理类 App 完全够用）
  • 部分平台特性兼容需要额外处理
B

原生双端开发

Android 用 Kotlin，Windows 用 C#/.NET，各自原生开发。

优点

  • 每端体验最佳、流畅度最好
  • 可以充分利用系统功能（指纹、人脸等）

缺点

  • 两套代码，两套技术，开发量翻倍
  • 未来维护和改功能成本高
  • 两套界面体验需要各自打磨
C

纯 Web 方案

做成一个 PWA（渐进式 Web 应用），浏览器打开就能用，Android 可以装到桌面上。

优点

  • 最简单，只要有浏览器就能跑
  • 开发速度最快

缺点

  • 指纹/人脸识别支持差
  • 离线使用不稳定
  • Windows 体验不够"像软件"
  • 安全性和本地加密能力不如原生方案
